# レビューガイドライン (Review Guidelines)

ChatGPT Codex（GitHub App / Codex CLI）や AI エージェントが、本リポジトリの PR をレビューするときのガイドラインです。

---

## 1. 言語と書き方

- レビューコメントはすべて日本語で書いてください。コード識別子・ファイルパス・引用は英語のままで構いません。
- PR サマリ・提案文・コミット提案など、生成する文章もすべて日本語にしてください。
- 指摘ごとに「何が」「なぜ問題か」「どう直すべきか」を短く書いてください。
- ファイルと行を示してください。GitHub の suggestion ブロックが使えるときは使ってください。

---

## 2. 重要度の基準

| ラベル | 付ける条件 | 例 |
|---|---|---|
| `[Blocker]` | マージするとビルド・テスト・既存機能が壊れる | ビルドが通らない、保存した JSON が読み込めない |
| `[Major]` | 実際に誤動作する。実装者がそのとおりに作ると誤動作する矛盾がある。§5 の重点観点や `.claude/rules/` の規約に違反している。明らかに性能が落ちる | 境界値で範囲外アクセス、計画書の 2 か所で既定ポートが違う、`Shared/Schema` の外で JSON を読み書きしている |
| `[Minor]` | 動作には影響しないが、直したほうがよい | 命名の不統一、説明が足りない |
| `[Nit]` | 表記ゆれ・誤字 | 句読点、全角半角 |
| `[Future]` | 今の PR の範囲外。後続タスクで考えればよい | 計画書で「DT-3 で詰める」とした細部、まだ無い仕組みのすり抜け方 |

- **計画書（`Docs/*-plan.md` など）のレビュー**では、まだ実装していない仕組みの細かい穴は `[Future]` にしてください。`[Major]` にするのは、事実の誤りと文書どうしの矛盾だけです。
- 意図的な悪用への対策は求めません。本リポジトリの仕組みが防ぐのは「うっかり」までです。

---

## 3. 往復を減らすためのお願い

- 見つけた指摘は、1 回のレビューですべて出してください。
- 同じ種類の問題が複数の箇所にあるときは、1 件にまとめて箇所を列挙してください。
- ユーザーの依頼で再レビューする場合も、前回の対応で決まった方針を別の角度から蒸し返さないでください。方針に反対なら 1 件の `[Minor]` として理由を書いてください。
- レビュー依頼は 1 つの PR につき 1 回だけです。再レビューはありません。指摘は必ずこの 1 回で出し切ってください（[.claude/rules/feedback-review-convergence.md](../../.claude/rules/feedback-review-convergence.md)）。

---

## 4. 制約事項・禁止事項

- **スコープの遵守**: 進行中のフェーズ（[Docs/phase-status.md](../phase-status.md)）を外れる大規模リファクタリングの提案は控え、必要なら `[Future]` で分けてください。
- **フォルダ構成変更の禁止**: `Editor/` `Simulator/` `Runtime/` `Shared/Schema/` `Shared/Widgets/` `Docs/` の構成を変える提案はしないでください。
- **代替ビルドシステムの禁止**: qmake など CMake 以外の導入は提案しないでください。

---

## 5. 重点的に確認すべき観点

1. **`Shared/Schema` が JSON 入出力の唯一の実装か**
   - Widget / Screen / Project の型と JSON 入出力が、`Shared/Schema` 以外に漏れていないか。
2. **QML モジュール URI とアプリの `loadFromModule()` 引数の一致**
   - `HmiEditor` / `HmiSimulator` / `HmiWidgets` が一致しているか。
3. **QtQuick 標準型との QML ファイル名衝突**
   - `Canvas.qml` / `Button.qml` / `Rectangle.qml` のようなプレフィックス無しの名前がないか（`HmiButton.qml` のように `Hmi` プレフィックスが必須）。
4. **共有 QML モジュールの STATIC ビルド + plugin 直リンク構成**
   - `Shared/Widgets` を `MODULE_LIBRARY` で作っていないか。
5. **macOS の Qt バージョン罠**
   - `~/Qt/6.7.0/macos` を `CMAKE_PREFIX_PATH` に指定する変更は、AGL のリンクエラーで壊れるので警告してください。
