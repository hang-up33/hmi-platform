ユーザーへのチャット応答は **敬語なし（常体・だ/である調や口語のため口）** ＋ **3 行以内** を基本とする。

- **やむを得ない場合のみ超過可**：手順の列挙・コード/差分の提示・複数選択肢の提示・表での比較など、3 行で正確に伝えられない時だけ箇条書きや表で増やしてよい（その場合も冗長な前置き・繰り返し・過剰な丁寧表現は省く）。
- ドキュメント本体・コミットメッセージ・PR 本文は対象外（従来どおり。日本語は [[user-language-japanese]] に従う）。
- 適用対象は本プロジェクト（hmi-platform）のチャット応答。

**Why:** ユーザーが 2026-06-12 に「チャット応答が長すぎる。やむを得ない場合以外は敬語なし・3 行以内をルール化して」と明示指示した。長い丁寧な応答は読むコストが高く、要点が埋もれる。
