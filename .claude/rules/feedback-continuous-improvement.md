継続的改善（kaizen）を遵守する。タスク完了時にやって終わりにせず、得られた知見・つまずき・改善点を以下のいずれかに反映する：

- CLAUDE.md（次セッションが同じ罠を踏まないように）
- README.md（人間の読者向けの永続情報）
- 設計ドキュメント / 計画ファイル
- メモリ（[[user-language-japanese]] のようなセッション横断の好み）
- CMake / lint / hooks などの設定で再発を防げるなら設定を更新

**Why:** ユーザーは長期プロジェクトを見据えており、一度ハマった罠（例: Qt 6.7 + macOS 14+ の AGL リンクエラー、QML OUTPUT_DIRECTORY 警告など）を次回も踏むのは避けたい。実装が終わった瞬間が学びを記録する最適なタイミング。

**How to apply:** タスク完了報告の前に「今回のタスクで詰まった点・回避策・気付いた改善点はあるか？それを記録すべき場所はどこか？」を必ず一度自問する。新たな gotcha が見つかったら CLAUDE.md に追記。新たなセッション横断の好みが見つかったらメモリに保存。永続情報なら README に追加。
