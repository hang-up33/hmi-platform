# 進捗の保存と再開 / Obsidian Persistence

理解度表は **1回きりの知見メモではなく、更新し続ける進捗表**。そこが `obsidian-knowledge-capture`（知見の追記型）と違う。ここでは「対象ごとに1ノート」を持ち、理解度表ブロックを毎回最新版へ差し替える。

## ノートの単位と場所

- **対象ごとに1ノート**。ファイル名: `理解度_<対象名>`（例: `理解度_PR123_Meter`）。
- **`<対象名>` の決め方（上から順に、決まった時点で採用）**。本リポジトリはチケット管理ではなく **Task N / PR#** で回るので、それを軸にする:
  1. PR番号がある → `PR<NNNN>`（＋機能名。例: `PR123_Meter`）
  2. フェーズタスク番号がある → `Task<N>_<機能名>`（例: `Task49_Label_roundtrip`）
  3. ファイル／ディレクトリ対象 → その機能名・ディレクトリ名（例: `Schema_json_io`）
  4. どれも無い → 短縮コミットハッシュ（例: `commit_12f5a9db4`）
  再開時に同じ規則で引けるよう、一度決めた対象名はぶらさない。
- frontmatter は同梱テンプレート（[../assets/rikaido-table-template.md](../assets/rikaido-table-template.md)）に従う（`note_type: project` / `category: コード理解` / project / module / tags / keywords）。ユーザーが Obsidian 側で `obsidian-knowledge-capture` 等の知見ノート運用をしている場合は、その検索キーに合わせて他の学習ノートと横断検索できるようにする（このスキル単体では上のテンプレートが正）。
- 本文構成は [../assets/rikaido-table-template.md](../assets/rikaido-table-template.md) を使う（全体図 → 理解度表 → 学習ログ → 未確認事項）。

## 保存フロー（Obsidian MCP が使える場合）

1. **検索してから書く。** まず `理解度_<対象名>`、対象の PR/チケット番号、主要ファイル名で既存ノートを検索する。
2. あれば **その理解度表ブロックを丸ごと最新版に差し替える**（追記ではなく置換。表は常に1つの最新状態）。無ければテンプレートから新規作成する。
   - **全体図は必ず ````mermaid ... ```` のコードブロックのまま保存する**（チャットに出した mermaid ソースをそのまま貼る）。箇条書き・散文に書き下してはいけない。Obsidian で図としてレンダリングされないと全体地図の意味が無いため。新規作成時はテンプレートの `## 全体図` の mermaid ブロックを自分の図で置き換える。
3. 学習ログ（Session Log）には **1行だけ追記** する（例: `2026-07-15: file1 を 0→100%、file2 の「なぜQList?」が残課題`）。ここは差分の履歴なので追記でよい。
4. 保存後、「どのノートに何を保存したか」を1〜2行で報告する。

> Daily note への概要追記は必須ではない。ユーザーが望めば、`obsidian-knowledge-capture` の流儀で当日の Daily note に「詳細ノートへの内部リンク＋1行サマリー」を足す。

## フォールバック（Obsidian MCP が無い場合）

進捗の継続がこのスキルの命なので、**下書きを返すだけで終わらせない。ローカルの Markdown に必ず書き出す。**

- 保存先（既定）: `~/.claude/code-comprehension/理解度_<対象名>.md`
  - リポジトリを汚さず、セッションをまたいで残る場所。ユーザーが別の場所を指定すればそれに従う。
  - スクラッチパッドは **使わない**（セッション終了で消えるため、再開できない）。
- **書く前にまず `~/.claude/code-comprehension/` に同名ノートが無いか確認する**（MCP版と同じ「検索してから書く」）。あれば理解度表ブロックを差し替え、無ければ新規作成する。フェーズAを2回走らせても既存の進捗を上書きしないため。
- 中身は Obsidian ノートと同じ（frontmatter 付きのまま書いてよい。後で Obsidian に取り込める）。
- 保存後、**「Obsidian MCP が無かったのでローカルに保存した。パスは ~/.claude/code-comprehension/… 。MCP が復活したら Obsidian に取り込むと一元管理できる」** と明示する。

## 再開フロー / Resume

1. まず Obsidian MCP で `理解度_<対象名>` を検索。無ければローカル控え（`~/.claude/code-comprehension/`）を探す。
2. 見つかった理解度表を読み込み、現状（各ファイルの理解度%・分かっていない部分）をユーザーに要約提示する。
3. `100%` のファイルは飛ばし、`未着手`／中途のファイルからフェーズBを再開する。
4. セッション終了時は必ずフェーズCで保存し直す（表の最新化＋学習ログ1行）。
