argument-hint: "作りたい skill が実行する内容（例: 実装を完了させるワークフロー / PR のレビュー指摘をまとめる 等）"

今までの会話履歴を参照して、$ARGUMENTS を実行する skill を作成してください。
skill-creator skill を使い、レビューを受けながら段階的に作ってください。

補足（この定型プロンプトの意図）：
- **会話履歴が主な入力**。直前までのやり取りで実演したワークフロー・踏んだ罠・ユーザーの修正を抽出して skill 化する。ゼロから発想するのではなく、今起きたことを再利用可能な形に固定するのが狙い。
- **skill-creator の作法に従う**：意図確認 → 下書き → （必要なら）レビュー/評価 → 反映、を回す。本プロジェクトの skill は `.claude/skills/<name>/SKILL.md`（frontmatter は `name` / `description` / `origin`、日本語、小文字+ハイフン命名）で、既存 skill と重複せず**詳細は既存 skill へ委譲**する形にする。
- 実行すると実 PR を作る等で定量ベンチが不適切な「ワークフロー系」skill の場合は、無理に評価ループを回さず内容レビューで詰めてよい（skill-creator もワークフロー/主観系は定性評価でよいとしている）。
